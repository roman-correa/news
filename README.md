# 🏙️ Compra/Venta Medellín

> Real estate price predictor and opportunity finder for the Medellín market — built with XGBoost, Bayesian hyperparameter search, and a Streamlit dashboard.

---

## What it does

- **Predicts** the rental or sale price of any apartment or house in Medellín given its size, location, and features
- **Finds opportunities** — properties listed below their model-estimated value by more than 20%
- **Maps** those opportunities with points of interest nearby (restaurants, supermarkets, parks, transit, etc.) pulled live from OpenStreetMap
- **Explores** the market through price distributions, area vs price scatter, and barrio rankings

---

## Model performance

| Model | R² (test set, log-space) |
|---|---|
| Arriendo (rental) | ~0.78 |
| Venta (sale) | ~0.86 |

Both models use XGBoost with hyperparameters tuned via Bayesian search (40 iterations × 5-fold CV). R² is computed on a held-out 20% test set, never seen during training or hyperparameter search.

## Setup

### Requirements

- Python 3.11+
- Git LFS (for large files)

### Install

```bash
git clone https://github.com/roman-correa/Compra_Venta_Medellin.git
cd Compra_Venta_Medellin
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

> **Windows note:** if `geopandas` fails, install via conda:
> ```bash
> conda install -c conda-forge geopandas
> ```

### Train the models

Using existing scraped data (fast, ~10–20 min):
```bash
python train.py --skip-scrape
```

Scrape fresh data from metrocuadrado.com, then train:
```bash
python train.py
```

Train only one model:
```bash
python train.py --skip-scrape --mode arriendo
python train.py --skip-scrape --mode venta
```

### Run the app

```bash
streamlit run app.py
```

Opens at `http://localhost:8501`

## Features

### 🔮 Predictor
Enter the barrio, property type, area, bedrooms, bathrooms and parking spots. The model returns an estimated price, price per m², a confidence range, and a table of comparable real listings in the same barrio.

### 📊 Data explorer
Browse the full dataset with filters by barrio and price range. Tabs for price distribution, price vs area scatter, and a ranking of the top 25 barrios by median price.

### 🗺️ Opportunity map
Properties where the listed price is more than 20% below the model's estimate. Select any row to zoom in on the map and load nearby points of interest (restaurants, supermarkets, parks, transit, gyms, schools, banks) from OpenStreetMap within 800m.

## How the model works

### Feature engineering
| Feature | Description |
|---|---|
| `area`, `habitaciones`, `baños`, `parqueaderos` | Raw property attributes |
| `axe`, `axh`, `axa` | Area per space, area per bedroom, area squared |
| `ppmc`, `pppz`, `pppp` | Neighbourhood price per m², per space, per parking |
| `new_index` | Barrio price rank (0–100) |
| `barrio_count` | Number of listings in the barrio |
| `barrio_te` | Smoothed target encoding of the barrio (train-only, no leakage) |

### Target encoding
Each barrio's mean log-price is blended with the global mean using Bayesian smoothing: `smoothing = count / (count + 10)`. Barrios with fewer than 10 listings lean heavily on the global mean, preventing overfitting on thin neighbourhoods.

### Training pipeline
1. Scrape ~10 000 listings from metrocuadrado.com
2. Spatial join with the official Medellín shapefile to assign authoritative neighbourhood names
3. IQR outlier removal (3× fence to keep luxury properties)
4. Train/test split (80/20) before any target-derived features are computed
5. Bayesian hyperparameter search: 40 iterations × 5-fold CV over 8 dimensions
6. Refit best params with early stopping on a 15% validation split
7. Evaluate on the held-out test set

## Data source

Listings scraped from [metrocuadrado.com](https://www.metrocuadrado.com) — Colombia's largest real estate portal. Neighbourhood boundaries from the official Medellín municipal shapefile. Points of interest from [OpenStreetMap](https://www.openstreetmap.org) via the Overpass API.
